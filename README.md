# 📌 About The Project

**Food Lover** is a modern restaurant website designed to provide
visitors with an attractive and enjoyable browsing experience.

The website focuses on modern UI, responsive layouts, food presentation,
restaurant information and an easy-to-use navigation experience.

This project was created as part of my journey as a **Front-End Developer**
to practice building real-world responsive websites.

---

# ✨ Features

- 🍕 Modern restaurant design
- 📱 Fully responsive layout
- 🧭 Responsive navigation bar
- 🍔 Food menu sections
- 👨‍🍳 Restaurant information
- ⭐ Attractive UI components
- 📸 Food images and visual sections
- ⚡ Interactive JavaScript elements
- 📱 Mobile-friendly design
- 💻 Desktop & tablet support
- 🎨 Clean and organized interface
